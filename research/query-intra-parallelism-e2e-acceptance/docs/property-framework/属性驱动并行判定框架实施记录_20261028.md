## 测试的反向核查

四组隔离源码副本用于检查测试能否识别故障，仓库源码保持正向验证版本。

- 返回第一条输入而丢失第二条输入时，分支保留断言失败。
- 把父节点要求的顺序写成输入提供顺序时，排序与合并断言失败。
- 把未知节点的分布写成单分支时，保守推导和显式收集断言失败。
- 把多个分组集映射到去重原因时，原因映射断言失败。

每组都保存故障副本、执行前身份、编译字节、实际加载身份及失败断言。预期失败的副本仅用于验证测试识别错误的能力，正向测试结果由上一节的独立运行给出。

数据来源：反向核查结果为 `/root/property-a-artifacts/A2-20261028T142500+0800/reverse-02/summary.json`，每组的 negative-verdict.json 包含断言栈与加载身份核验数。全部失败尝试原件保持在同一归档下。
