结论：A0 至 A6 已满足退出条件。完整 DataNode 套件的 784 个可运行测试类全部有报告，共执行 4995 项测试，失败和错误均为零，跳过 50 项。最终定向、两种语言构建和四组双节点查询均通过，A 可以按一个完整提交发布，随后编写 B 的两份待审文档。

## 查询计划与结果要求

查询在补充收集或排序节点后，必须保留全部输入并满足父节点要求。两个来源分别含同一键的两行与三行时，最终必须只输出一个分组，计数为五。A 将这些判断集中到独立组件，并保持已有执行入口。

数据来源：[框架设计](属性驱动并行判定框架设计_20261027.md)和[框架实现规划](属性驱动并行判定框架实现规划_20261027.md)规定实现与验收范围。

## 实现组成

提供者从物理节点和排序记录推导属性，强制器保留全部输入并按要求插入收集、排序或合并排序。逻辑分区要求采用已验证的保守收集，受限分组哈希交换继续由专用入口构建。

计划器保存不可变决策，并从冻结值生成文本解释。例如，规划后修改原输入的 ID，重复渲染仍必须显示规划时捕获的值。未知节点采用缺少证明时的保守处理，扫描资格沿用既有规则。

两个 ByteBuffer 重载复用既有流式编码，避免表模型类型缺失和字段次序分歧。架构测试在资源不足时抛出断言失败，交换层继续验证主动 OOM 的异常处理。四个生产方法的测试专用标注已与实际调用关系一致。

数据来源：核心组件为分布包的 `PlanPropertyProvider`、`PropertyEnforcer`、`PropertyEnforcementDecision` 和 `FallbackReason`。限定修复位于 `TypeProvider.serialize(ByteBuffer)`、`PlanFragment.serialize(ByteBuffer)` 及测试包的 `AnnotationTest`，准确修改记录见[实施记录](属性驱动并行判定框架实施记录_20261028.md)。

## 测试与覆盖

最终定向回归覆盖 32 类、339 次顶层 JUnit 调用，失败数为零，五次按参数化条件跳过。配置隔离在全开和全关两种初值下各运行 79 次内部调用，内部调用单独统计。128 份同配置计划快照与冻结基线一致。

全部 21 个通用合并调用和 13 个保留构造均有实际执行证据。721 条决策和 72 个加载类身份关联到对应测试与配置。四个隔离故障副本分别验证未知属性误判、排序要求误用、遗漏输入和原因映射错误会被断言识别。

合同覆盖 13 个节点家族，校验器的 23 项自测通过，运行所有权解析器的 21 项自测通过。新增十项序列化测试逐符号核对 SQL 类型和剩余字节。架构测试在 2 GiB 堆下通过，在 128 MiB 堆下明确报告检查无法完成。

例如，删除一个双输入结果的第二条分支，保留断言必须失败。把投影合同的真假标记翻转，离线校验必须拒绝。两种负例分别验证 Java 行为断言和合同校验自身的有效范围。

数据来源：最终定向为 A6 的 `attempt-06/a6-component-exit.json`，完整模块为 `full-datanode-06/full-suite-exit.json`，逐类覆盖为同目录的 `final-suite-coverage.json`，调用覆盖为 `decision-coverage-final-01/coverage-verdict.json`，合同为 `verifier-03/report.json`，架构正反核查为 `annotation-oom-contract-02/verdict.json`。逐功能的测试对应关系见[测试核查](属性驱动并行判定框架测试核查_20261028.md)。

## 双节点与构建

候选和对照各部署一个 ConfigNode 与两个 DataNode，使用最终源码重新构建的英文发行包。普通重复键、空值键、倾斜和空输入四组查询均与确定性预期的完整多重集及 SHA 一致。每个非空用例分别检查真实 DataNode、唯一片段、四条交换边和最终桶归属。

普通输入有十二行并产生三个分组，空值输入有十六行并产生四个分组。倾斜输入有八十四行，两个分组的计数分别为八十和四。空输入成功返回零个分组，JDBC 保留 SQL 类型与空值。

分析查询按每类最多三次观测执行，只接受所有片段均完成的快照，拒绝的快照也单独保存。接受记录按对应分析查询的 ID 检查所有权。六个服务节点全部停止，端口均已释放。

例如，双源双桶必须包含四条不同交换边，且同一桶列的两条边必须进入同一个片段。若两条边进入不同片段，验收器会拒绝该运行快照。

数据来源：A6 的 `isolated-distribution-06/exit.json` 与 `isolated-distribution-06/zh-reactor-01/exit.json` 分别记录英文发行包与中文编译，实际查询为 `two-datanode-05/acceptance.json`，观测记录为同目录的 `runtime-observations.json`，运行类与动态库为 `runtime-after.json`，冻结日志为 `frozen-loaded-runtime.json`，停止核查为 `stop-verification.json`。
