# B 静态数据并行统一文档复审修订记录

日期：2026-10-31

本版依据 `/root/w5-docs/B_静态数据并行统一文档复审_20261031.md` 的新发现修订，作为 B1 起步实施依据。上一版实施版文件保留不覆盖。

## 已修订

- 设计文档明确首版 `nominalShareBytes` 恒不高于兼容下限，额度发布只能做跨片段原子取最小收紧，诊断目标不反向改变生效额度。
- 设计和规划的 32 桶退出条件直接断言 `nominalShareBytes=125,703`（2 GiB 堆、32 查询线程的冻结配置），并与 32 个 channel 身份、一个上游记账键分别核对。
- 明确同节点跨片段共享队列的记账键属于上游生产片段，即使接收方先创建队列也不改变归属。
- 明确 `SharedTsBlockQueue` 生产 getter 是本地扫描路径读取 query、片段和 planNodeId 的入口，禁止使用包装层的空字段推断。
- 资源观测补充片段级快照、注销前回执和 query 级假归零反例，要求在静止点用同一轮片段快照求和。
- 关闭槽数据来源补齐 `FragmentInstanceContext.allDriversClosed` 的 `CountDownLatch` 字段、初始化、递减和等待点，并保持 data/schema 两条执行入口覆盖。
- 轮询门限继续使用构造时预算的实算值，并要求候选与基线逐步比较下标、发送序列和通道分布；手工额度注入反向测试明确为测试专用。
- 隔离服务验收保留开关与配置原字节、权限、SHA 和启动参数，停止服务后逐文件恢复核对。
