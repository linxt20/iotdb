## 已处理事项

1. 删除分隔线之后的旧保留正文，使每份文件只有一套生效章节，并补充目的、摘要、结论和未决问题。
2. 补齐 `driverWallNanos`、`driverOutputBytes`，统一 thrift、manifest、D/E 清单中的 `driver*` 命名。
3. 将聚合成本三项标记为 `FRAGMENT_LOCAL_ONLY`，说明暂不进入 response 和释放时清零风险。
4. 将 active/blocked/completed driver 的来源改为待新增 `IDriverScheduler/DriverScheduler` 快照接口，queued 使用就绪队列长度，completed 使用状态转移。
5. 为 C4 写明逐节点 timeout 的 RPC deadline 重载、配置优先级、Future fallback 和客户端归还规则。
6. 将阻塞比例算例补成 `blocked=50`、`ready=200`、`ratio=20%`，把统计屏障测试移到 C2，并补充真实单节点测试复用 `DeviceTableScanParallelPipelineTest` 夹具语义的要求。
7. 将文本 Drawer 测试标为必须新增，修正 thrift 确切行号，C6 改为依赖 Java 17 profile 的六条 opens，并补充全量和日常定向两条命令。
8. 为 CPU 采样和 DriverScheduler 计数增加可测的开销上限与证据要求。
