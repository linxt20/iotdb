## P1 处理

- 终态缓存门控明确为 EXPLAIN ANALYZE；普通查询返回 NOT_SUPPORTED/NOT_FOUND；补充五分钟缓存窗口、说明列/CTE 行限制和空 response 非成功语义。
- 终态写锁与显式读锁分路径；driver recorder 改为快照 side-channel；hash 在锁外计算；QueryStatistics 增加一次性快照。
- merge/数值解析/QueryPlanStatistics 空值必须 finally 解锁并继续资源清理。
- 片段集合拆分为 returnable 与 intentionallyIgnored，旧计数保持兼容，新 runtimeSnapshot 记录差集。
- CPU 只允许 ThreadMXBean 采样或 unsupported，禁止把 elapsed wall 改名 CPU。
- 两个 Drawer、指标树渲染测试和 StatisticsMergeUtil/SpecifiedInfoMergerFactory 纳入 C0/C6 主回归。
- C2 明确基线已有终态 listener 的 driver 补写顺序，禁止重复实现。
- 有序并行后缀、driver first/last、ready/block、active/queued/completed、memory peak、exchange bytes 均标明新增来源或 unsupported。
- fetch 改为逐节点 timeout/catch，单节点失败不阻断其他节点。
- fold 不再作为结构化快照身份或增量主键，重复同基号子扫描必须稳定。
- C6 命令补 -am、Java 17 opens 和可复制的一行参数。

## P2 处理

已在修订正文中固定：

- datanode.thrift 的真实路径、结构位置与生成模块；
- QueryPlanStatistics/MPPQueryContext 的 query 级成本来源及 coordinator-local 限制；
- 五个无空值卫读取方法的 unsupported 处理；
- 三族传输键的可见性；
- 实际 endpoint 与节点自报 endpoint 的区分；
- 文本 driver 字段落点和数值排序；
- B6 NaN 证据来自验收探针 Gson 转储，不归因生产 Drawer；
- RuntimeSnapshotValidity 与 RuntimeSnapshotValiditySet 拆成独立公共文件；
- 工作单元/分区号只允许结构化字段；
- B-resource-freeze 与 runtime-snapshot-final 术语消歧。

## 放行结论

C0、C1 可在修订契约下开始。C2–C6 必须先按本修订版完成 thrift、锁协议、字段来源和测试矩阵实现；本轮只修改文档，没有改生产代码、没有运行 C 测试、没有 commit/push。
