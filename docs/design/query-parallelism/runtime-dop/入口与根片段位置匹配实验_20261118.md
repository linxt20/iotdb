# 入口与根片段位置匹配实验

**目的**：规定五配置性能对照中的入口选择、根片段位置核验和结果解释。

**摘要**：相同查询可以从不同 DataNode 进入，结果根片段还可能位于另一节点。固定连接第一个节点，不能保证各部署具有相同的结果传输关系。本文以设备区域、文件归属和原生计划确定入口，再核验实际诊断片段。既有固定入口样本与位置因子样本分别保存。

**结论**：匹配实验为每个部署选择承载有序结果根所在区域的入口，非有序虚拟区域根则继续随入口执行。全部 55 个查询与配置组合必须证明结果根与入口位于同一 DataNode，之后才允许计时。新实验保留相同查询、计时函数、完整结果比较和重复次数，完整逐样本 lane 身份仍单列待补。

## 比较对象

实验比较相同 SQL 在五个配置中的完整执行代价。配置包含原生上游、固定一名 worker、固定八名 worker、自适应，以及 v4 固定八版本参照。每个端点都属于一套单 ConfigNode、双 DataNode 部署，全部运行在同一物理主机。

不同部署的区域分配可以相同，区域到 DataNode 的放置仍可能不同。例如，区域二在一套部署由第一个节点承载，在另一套部署由第二个节点承载。若客户端都连接第一个节点，结果根可能分别采用同节点和跨节点的传输关系。

源数据回读与区域成员计划覆盖全部 370 个客户端。按区域、时间分区和文件摘要比较时，五侧文件内容相同。这个比较保留文件出现次数，忽略 DataNode 名称与文件名。实际 DataNode 放置和 JVM 运行状态分别记录。

数据来源：完整数据实验的文件清单、1,850 份设备路由计划，以及两个版本的有序普通查询运行快照。

## 入口选择

入口选择使用原生计划和区域文件归属，规则在新计时前冻结。有序查询的已观察结果根位于区域二，实验选择实际承载该区域的节点。非有序查询的诊断根使用虚拟区域，其位置必须继续通过新入口上的诊断确认。

该规则统一应用于全部五个配置。它使用执行关系，不按每个查询的测量时延挑选端点。入口选择发生在连接建立之前，其成本与原协议的连接建立一样位于查询计时窗外。

例如，一个部署的区域二位于第二节点，则客户端连接该节点的 RPC 地址。诊断结果中的根片段内部地址也必须对应这个节点。RPC 端口和内部端口属于同一节点身份，必须通过部署清单关联，不能只比较共同的回环 IP。

数据来源：运行器保存的入口选择清单、实际部署清单和原生 EXPLAIN ANALYZE VERBOSE 输出。

## 根片段核验

核验使用当前单表、双源查询族的片段结构。结果根具有交换输入，其本片段的算子树包含合并或收集逻辑。数据源片段则包含扫描算子。每个保留完整根统计的诊断必须找到唯一的结果根，并核对其实际内部端点和终态。原生诊断遗漏根时，使用既有普通 SQL 审计器补充该查询的实际根证据。

例如，同一诊断包含一个合并片段和两个扫描片段时，核验必须选择合并片段。片段序号或区域数字相同，只能辅助定位，不能独立证明其为结果根。诊断查询与普通计时查询各自保持自己的身份。

全部根角色确认与入口同节点后，运行器才记录计时开始。普通 SQL 补证必须同时核对 roster 的 root 标记和冻结统计的实际端点，保持各自查询身份。缺失补证、歧义、错误位置或非 FINISHED 根会阻止测量。缺少子片段的诊断继续保持其范围限制，完整源拓扑与资源结算仍引用独立普通查询审计。

数据来源：匹配运行器的根核验回执，以及标准普通 SQL 审计的完整片段和资源记录。

## 样本与计时

匹配实验保持十一类查询、五个端点、五块预热及十五块测量，共 1,100 次查询。每次查询继续执行完整类型结果比较，并匹配新 FINISHED 原生查询 ID。客户端计时和原生服务端耗时分别报告。

原有固定入口的 1,100 次查询、入口因子的 80 次查询，以及带 JFR 的 210 次诊断均作为独立实验保存。统计区间按各自实验的配对块计算。例如，两个条件各十五块测量，必须分别报告十五块，不能合并成三十个同条件样本。

匹配入口可以消除一个已识别的位置差异，其他差异仍需单独解释。JVM 热状态、完整 lane 内容、历史和缓存不能由端点匹配自动证明。动态主实验继续采用长查询中的背景负载升降，其场景与稳定负载版本对照分别执行。

数据来源：sc01 工程根为 `/root/rivermind-data/iotdb-paper-experiments-20261117`。执行入口为 `scripts/measure_electricity_root_local_r2_20261118.py`。输出为 `electricity-ordered-v5-r2/measurement-root-local-02/`。冻结的固定入口实验位于同一 cohort 的 `measurement-with-v4-02/`，入口因子实验位于 `ordered-coordinator-placement-01/`。
